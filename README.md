### Contributing

This is a fork of the original [Zen Browser](https://github.com/zen-browser/desktop). For issues with the original Zen Browser, please report them on the [original GitHub Issues page](https://github.com/zen-browser/desktop/issues/) and for feature requests, you can use [original Github Discussions](https://github.com/zen-browser/desktop/discussions).

Infflow is based on the open-source Zen Browser project. We welcome contributions from the community! Please take a look at the [contribution guidelines](./docs/contribute.md) before getting started!
